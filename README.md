## Условие

Дано положительное целое число `n`. Найдите сумму квадратов первых `n` натуральных чисел: 1² + 2² + … + n².

**Примеры**

```
Вход: n = 2
Выход: 5
Пояснение: 1² + 2² = 1 + 4 = 5

Вход: n = 8
Выход: 204
Пояснение: 1² + 2² + 3² + 4² + 5² + 6² + 7² + 8² = 204
```

## Как выполнить

1. Один человек из команды нажимает **Fork** (вверху справа) и добавляет напарника: Settings → Collaborators → Add people.
2. Оба клонируют форк и открывают его в VS Code:
   ```
   git clone https://github.com/<ваш-ник>/p42-02-sum-of-squares
   cd p42-02-sum-of-squares
   code .
   ```
3. Впишите в таблицу «Команда» выше свои ФИО и ники GitHub.
4. В `Program.cs` напишите решение внутри метода `SumOfSquares` (вместо строки `return 0;`). Метод `Main` и `Check` не меняйте.
5. Запустите:
   ```
   dotnet run
   ```
   Все проверки должны показать `OK`.
6. Сохраните работу в GitHub (коммитят оба участника):
   ```
   git add .
   git commit -m "Решение"
   git push
   ```
